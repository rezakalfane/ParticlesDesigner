Custom design

Design a look in the Designer, press Embed → Download JSON, and load it. Custom formulas (AI-invented shapes) compile in the background, so switching never freezes the page. 

import { ParticleField, fetchLook } from "particles-designer";

const field = new ParticleField("#particles", {
  look: await fetchLook("./looks/lissajous-bloom.json"),
  interactive: true,
});
field.setLook("deep-sea"); // transitions between custom and factory shapes
