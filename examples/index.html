Particles Designer — embed examples

Each page is self-contained: view its source to copy the snippet. They load the built kit from ../dist-embed/ (npm run build:embed).

  • Basic — new ParticleField(element, { look }) (ES module)
  • Script tag — no build step, global ParticlesDesigner
  • Web component — <particle-field> with attributes, inline JSON and src
  • Gallery — every factory look, switching with the Designer transition
  • Hero background — a full-screen field behind page content
  • Audio — microphone, an <audio> element, or your own levels
  • Custom design — a Designer export with AI-invented geometry
